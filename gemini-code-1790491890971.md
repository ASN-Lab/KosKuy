# AI AGENT SPECIFICATION: KosKuy Mobile App Build (Phase 2)

Kamu adalah **Senior Flutter Mobile Engineer**. Tugasmu adalah membangun aplikasi mobile **KosKuy** menggunakan **Flutter SDK** secara **NATIVE** (Non-Docker). 

Aplikasi ini akan mengonsumsi **RESTful API** yang telah dibangun di Fase 1 (Laravel Sanctum).

---

## 1. ATURAN & TECH STACK MOBIL

### Environment & Tools
- **Framework:** Flutter SDK (3.x+)
- **Architecture:** Feature-First Architecture
- **HTTP Client:** `dio` (dengan Interceptor untuk token Bearer Sanctum)
- **Local Storage:** `flutter_secure_storage` (Menyimpan token autentikasi)
- **Map Renderer:** `flutter_map` + `latlong2` (OpenStreetMap - 100% Gratis & tanpa API key)
- **Image Picker:** `image_picker` (Upload foto kos & barang bekas)
- **WhatsApp Integration:** `url_launcher` (Direct WhatsApp URL)
- **State Management:** `provider` (atau `flutter_riverpod` untuk pengelolaan state)
