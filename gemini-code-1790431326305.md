# AI AGENT SPECIFICATION: KosKuy Monolith MVP Build

Kamu adalah **Lead Full-Stack Engineer**. Tugasmu adalah membangun sistem backend dan web **KosKuy** menggunakan arsitektur **Laravel Monolith Non-Docker** yang efisien, ringan, dan siap pakai untuk kebutuhan MVP.

Website publik dan Admin Panel akan dibangun terlebih dahulu, serta disiapkan pula seluruh **RESTful API Endpoints** yang nantinya dipanggil oleh aplikasi mobile (Flutter).

---

## 1. ATURAN & STACK TEKNIS UTAMA

### Environment & Tools
- **Framework Backend & Web:** Laravel 11/12 (PHP 8.3+)
- **Frontend Assets:** Vite + Tailwind CSS + Alpine.js (Bawaan Laravel)
- **Admin & Moderation Panel:** FilamentPHP v3
- **Authentication:** Laravel Sanctum (Session-based untuk Web/Filament, Bearer Token untuk Mobile API)
- **Database:** Single MySQL Database (`koskuy_db`), dijalankan secara native di mesin lokal (tanpa Docker).
- **Architecture:** Simplified Monolith (1 Codebase).

---

## 2. SKEMA DATABASE & MIGRASI (`database/migrations`)

Buat migrasi tabel berikut beserta relasi *Foreign Key* yang tepat:

### 1. `users`
- `id` (PK)
- `name` (string)
- `email` (string, unique)
- `password` (string)
- `phone` (string) -> Nomor WhatsApp aktif
- `role` (enum: `'student'`, `'owner'`, `'admin'`) -> default: `'student'`
- `email_verified_at` (timestamp, nullable)
- `timestamps`

### 2. `categories` (Kategori Barang Bekas)
- `id` (PK)
- `name` (string) -> Contoh: Buku, Elektronik, Furnitur, Alat Rumah Tangga
- `slug` (string, unique)
- `timestamps`

### 3. `kos_listings`
- `id` (PK)
- `owner_id` (FK -> `users.id`, cascade delete)
- `title` (string)
- `description` (text)
- `price_per_month` (decimal: 12,2)
- `gender_type` (enum: `'putra'`, `'putri'`, `'campur'`)
- `latitude` (decimal: 10,8, nullable)
- `longitude` (decimal: 11,8, nullable)
- `address` (text)
- `is_available` (boolean, default: true)
- `timestamps`

### 4. `kos_facilities`
- `id` (PK)
- `kos_id` (FK -> `kos_listings.id`, cascade delete)
- `facility_name` (string) -> Misal: "AC", "Wi-Fi", "Kamar Mandi Dalam"

### 5. `kos_images`
- `id` (PK)
- `kos_id` (FK -> `kos_listings.id`, cascade delete)
- `image_path` (string)
- `timestamps`

### 6. `thrift_products`
- `id` (PK)
- `seller_id` (FK -> `users.id`, cascade delete)
- `category_id` (FK -> `categories.id`, cascade delete)
- `title` (string)
- `description` (text)
- `price` (decimal: 12,2)
- `condition_status` (string) -> Contoh: "85% Layak Pakai"
- `is_sold` (boolean, default: false)
- `timestamps`

### 7. `thrift_images`
- `id` (PK)
- `thrift_id` (FK -> `thrift_products.id`, cascade delete)
- `image_path` (string)
- `timestamps`

## 3. PENGEMBANGAN WEBSITE (PHASE 1)

Website publik dibangun menggunakan Blade Template + Vite + Tailwind CSS untuk kemudahan akses pengguna dari browser desktop/mobile.

### Route & Controller Web (`routes/web.php`)
1. **Landing / Home Page (`/`)**:
   - Menampilkan Hero Section, Kos Populer/Terbaru, dan Produk Barang Bekas Terbaru.
2. **Katalog Kos (`/kos`)**:
   - Filter pencarian berdasarkan: rentang harga, tipe gender (`putra`/`putri`/`campur`), dan pencarian kata kunci nama kos.
   - Halaman Detail Kos (`/kos/{id}`): Tampilan foto, daftar fasilitas, lokasi, dan tombol **"Hubungi Pemilik via WhatsApp"** (format `wa.me/<phone>?text=...`).
3. **Katalog Thrift / Barang Bekas (`/thrift`)**:
   - Filter berdasarkan Kategori dan Pencarian Kata Kunci.
   - Halaman Detail Barang (`/thrift/{id}`): Detail kondisi barang, harga, foto, info penjual, dan tombol **"Chat Penjual via WhatsApp"**.
4. **Dashboard Admin (`/admin`)**:
   - Gunakan **FilamentPHP v3** untuk dashboard backend.
   - Fitur Admin: Management User, Moderasi Listing Kos, Moderasi Produk Thrift (Hapus postingan penipuan).
